# AI Agent Rules, Commands & Skills

A public collection of reusable rules, commands, and skills for AI tools like Cursor, Claude, and other AI coding agents.

## Overview

This repository contains practical files for building better AI-assisted workflows.

Here you can find:
- **Rules** — persistent instructions and behavioral constraints
- **Commands** — reusable prompts and workflow shortcuts
- **Skills** — focused instructions for specific tasks
- **Templates** — starter files you can copy and adapt

The repository is public so anyone can explore it, reuse parts of it, and build their own setup.

## What’s inside

```text
/
├─ rules/
├─ commands/
├─ skills/
└─ templates/
```

> Adjust the folder names if your real structure is different.

## How to use

1. Open the folder that matches your need.
2. Copy the file you want into your own project or workflow.
3. Adapt it to your stack, coding style, and preferences.

These files are meant to be reused, remixed, and simplified for real projects.

## Supported tools

This repository is mainly oriented toward:
- Cursor
- Claude
- GitHub Copilot
- Other AI coding agents that support custom instructions or prompt files

Some files may be tool-specific, while others are written to stay generic and portable.
